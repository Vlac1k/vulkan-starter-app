# Лабораторная работа №2: Камера и освещение

**Вариант 4:** усечённый правильный тетраэдр (грани: правильные треугольники и шестиугольники).

Программа написана на C++20 с использованием Vulkan, GLFW и ImGui. За основу взят код лабораторной работы №1 и стартовый код преподавателя.

## Условие

Отрисовать объект из первой лабораторной относительно камеры с единственным направленным источником освещения. Параметры камеры, источника света, материала (модель Блинна-Фонга) и рассеянного света (ambient) должны изменяться через интерфейс ImGui.

## Что сделано

- **Нормали** генерируются процедурно: для каждой грани считается векторное произведение двух её рёбер. Так как рёбра фигуры резкие, у каждой грани свои копии вершин (36 вершин).
- **Камера:** позиция, поворот (yaw и pitch), угол обзора, переключение перспективной и ортографической проекции.
- **Направленный источник света:** направление, цвет и интенсивность.
- **Рассеянный свет (ambient):** цвет и интенсивность.
- **Материал:** альбедо, цвет блика, коэффициент блика.
- **Модель Блинна-Фонга** реализована во фрагментном шейдере (ambient + diffuse + specular).
- Данные передаются в шейдеры через два набора дескрипторов: набор для сцены (камера и свет) и набор для модели (матрицы и материал).
- Из лабораторной №1 сохранены изменение позиции, поворота и растяжения фигуры и анимация по траектории.

## Как собрать

Нужны: компилятор с поддержкой C++20 (GCC 10+ или MSVC), CMake, Vulkan SDK (`glslc` должен быть в PATH).

```
git clone https://github.com/Valeria115/vulkan-starter-app.git
cd vulkan-starter-app
git switch lab2
cmake --preset mingw-debug
cmake --build build-debug --parallel
```

Для Visual Studio вместо `mingw-debug` используется пресет `msvc-debug`.
Библиотеки (GLFW, ImGui, vk-bootstrap, VMA, GLM) CMake скачивает сам при первой настройке.

## Как запустить

Запускать нужно из корня проекта, иначе не найдутся шейдеры:

```
./build-debug/vulkan-starter-app.exe
```

Для сборки через Visual Studio файл лежит в `build-debug/Debug/`.

## Интерфейс

В окне ImGui несколько разделов:

- **Camera:** позиция, yaw, pitch, угол обзора (FOV), тип проекции.
- **Directional light:** направление, цвет и интенсивность света, цвет и интенсивность ambient.
- **Material:** альбедо, цвет блика, коэффициент блика (shininess).
- **Object:** позиция, поворот и растяжение фигуры.
- **Animation:** пауза и воспроизведение, скорость, параметры траектории.

## Где что лежит

- `source/application.cpp` — код лабораторной (геометрия и нормали, камера, интерфейс, дескрипторы, отрисовка).
- `shaders/lit.vert`, `shaders/lit.frag` — вершинный и фрагментный шейдеры (освещение по Блинну-Фонгу).
- `CMakeLists.txt` — сборка (библиотека GLM и компиляция шейдеров).
